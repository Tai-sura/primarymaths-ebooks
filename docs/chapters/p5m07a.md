## Source facts

- Page structure: p1 cover (no folio), p2 blank/notes, p3–p5 Level 1, p6–p9 Level 2, p10–p11 Homework. Pages 10–11 are scans with no text layer.
- 59 questions: main 45 numbered 1–46 (**the sheet has no 29**), Level 1 = 32 (q1–q33), Level 2 = 13 (q34–q46), Homework = 14 (hw1–hw14).
- Dense worksheet layout: consecutive questions 10–12 pt apart, one big circle figure beside q4–q6, a printed answer table for q18–q23, and scans for Homework.

## How the answers show

Decision from `tools/layout_triage.py` (Stage 2a), then changed after the teacher saw the first build:

| | |
| --- | --- |
| Mode | `answerStamps` — the ANS's own red answer is cut and pasted back into its blank; MC and long questions stay inline |
| Why | 18 of 59 questions have no full-width blank row to cut at (q4–q5 sit beside the big figure, q18–q22 inside the table, q26–q31 and hw1–hw3/hw8–hw10 in packed scan rows), so the page cannot be opened there. The teacher's key already marks every fill-in answer in red, and the teacher asked for exactly that: the answer in the blank, no explanation. |
| `answerStamps` | the 46 fill-in questions: q1–q33, hw1–hw14 (stamps in `books/p5m07a/answers/`, 46 PNGs) |
| Inline, physics style | MC q34–q41 and long questions q42–q46 — region + page cut + `space` |
| Superseded | `answerCards` with a `?` chip (v148): it opened a card with the worked solution, which the teacher did not want |

A stamp is the ANS page cropped round one red answer (+2 pt margin) and drawn at the page point it came from, so it lands exactly on the key. The answers are visible with the page.

## Special cases

- **Anchors**: q4–q6 are indented (question number at x≈208 pt) so they need `extract.anchors` regexes; q18–q23 are table rows (number in a different cell) so they need regexes too; hw1–hw14 are on scanned pages with no text layer, so they use `extract.fixedAnchors` measured from the page image ink bands.
- **Regions**: dense pages get a 2 pt band on a blank row just under the question's text (never an inverted region).
- **Folio**: `folio.json` = `{"_skip": [1]}` — the cover prints no page number; the other 10 pages carry theirs.
- No media, no graphics, no review links in this book.
